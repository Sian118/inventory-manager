# Inventory Manager

A command line application to manage inventory for a retail, e-commerce, or automotive shop. 
Built as part of the TechOnSkills AI Developer Bootcamp Month 1 Capstone Project.

## Features
- Add a new item with name, quantity, price, and category
- Update stock quantity after a sale or restock
- Search or filter items by category or price range
- Mark an item as out of stock
- Data is saved to a JSON file so it persists between runs
